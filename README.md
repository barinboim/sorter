# Sorter 1.0 · нейминг-игра

Слова восьми языков падают по одному — раскидывай их в **GOOD** / **BAD**
стрелками. Раунд: 100 слов. На выходе — `.txt` с обеими корзинами и
комментариями для анализа в LLM. Тёмная неон-тема, без бэкенда.

## Запуск

```bash
python3 -m http.server 4180 --directory .   # из папки sorter/
# открой http://localhost:4180
```

## Управление

| клавиши | действие |
|---------|----------|
| `←` / `A` / `Space` | в корзину **BAD** |
| `→` / `D` / `Enter` | в корзину **GOOD** |
| `↑` / `W` | пропустить (вернётся в будущем раунде) |

Слово появляется по центру (метод Spritz: центральная литера подсвечена и закреплена
по центру — глаз не бегает). Меню (≡): языки в пуле, длина слова, сброс истории.

## Данные

Словари собираются **один раз оффлайн** из [kaikki.org](https://kaikki.org)
(Wiktextract, CC BY-SA) с опциональным частотным фильтром
([hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords)):

```bash
bash scripts/fetch_all.sh   # качает и собирает data/pool_*.jsonl (стримом)
```

Игра в рантайме в сеть не ходит. Подробности — в [CLAUDE.md](CLAUDE.md).
