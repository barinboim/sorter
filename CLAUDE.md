# Sorter 1.1 — игра-сортировщик слов для нейминга

> **Версии.** `sorter-classique/` — замороженная 1.0 («Sorter Classique», порт 4181):
> чистая механика good/bad без обучения. `sorter/` — **1.1**: тот же цикл плюс
> **адаптивный подбор** (рычаг 1) и **режим ковки** коинов (рычаг 2) — оба ниже.
> Всё алгоритмически, без LLM в рантайме.

Локальное браузерное приложение. Слова показываются по одному **по центру** (метод
Spritz, без падения); игрок раскидывает каждое в корзину **GOOD** или **BAD**
клавишами-стрелками. Раунд — настраиваемое число слов (по умолч. 100). По итогам: сохранение сыгранного
(без повторов в будущем), комментарии к словам и экспорт в `.txt` для последующего
смыслового анализа в LLM.

Это **второй инструмент** семейства Namer (рядом с матричным движком в корне репо),
самостоятельный и project-agnostic: общий пул из восьми языков, никакой привязки к
конкретному клиенту.

Бэкенда нет. Всё состояние — в `localStorage`. Словари — локальные файлы, собранные
заранее оффлайн (см. «Данные»).

---

## Как запустить

Статичный сайт без сборки, но из-за `fetch()` к локальным `.jsonl` нужен **локальный
сервер** (не `file://`):

```
python3 -m http.server 4180 --directory .   # из папки sorter/
# → http://localhost:4180
```

Конфиг для preview уже лежит в `.claude/launch.json` (имя `sorter`, порт 4180).
Зависимостей и npm нет; шрифты самохостятся в `assets/fonts/` — рантайм в сеть не ходит.

## Структура

```
sorter/
  index.html            # разметка: шапка, игра, итоги, меню, старт-оверлей
  style.css             # тёмная неон-тема (акцент #71FCE9), сетка, анимации

  data/
    pool_<lang>.jsonl    # игровые пулы (собираются скриптом, см. ниже)
    freq_<lang>.txt      # частотные списки (кэш сборки, в игре не нужны)

    README.txt           # источники и лицензии данных

    build_pools.py       # сборка pool_*.jsonl из дампов kaikki (одноразово)

  assets/fonts/          # woff2 + fonts.css (Inter, Spline Sans Mono)
  CLAUDE.md              # этот файл
```

## Языки (8)

`ru en fr it la grc el sa` — русский, английский, французский, итальянский, латынь,
древнегреческий, новогреческий, санскрит. Включение/выключение — тумблерами в меню.

Для **grc / el / sa** крупным токеном на карточке показывается **транслитерация**
(`tr`), а оригинальное письмо (греческица / деванагари) — мелким серым рядом.
Для остальных крупный токен — само слово (`w`).

## Модель данных пула

Одна запись `pool_<lang>.jsonl` = одна строка JSON:

```json
{"w": "такелаж", "g": "оснастка судна; снасти", "tr": null, "lang": "ru", "pos": "noun"}
```

- `w` — заголовок (для grc/el/sa — оригинальное письмо).
- `g` — краткий глосс (первое значение, **на английском** — так в дампах kaikki;
  для кросс-языкового анализа в LLM это удобно). Обязателен.
- `tr` — транслитерация латиницей. Обязательна для `sa/grc/el`, иначе `null`.
- `lang` — код языка.
- `pos` — часть речи (`noun/adj/verb`).

## Игровой цикл (game.js)

- Пул = объединение включённых языков **минус сыгранные** (множество в `localStorage`),
  **только однословные** (словосочетания исключаются) и в выбранном диапазоне длины.
- Фильтр **длины слова** (мин–макс букв) — слайдеры в меню; считается длина видимого
  токена (для grc/el/sa — транслитерации, комбинирующие знаки не в счёт). К новому раунду.
- На раунд берётся перемешанный пул; карточки идут по одной до заданного числа
  рассортированных (**Слов в раунде** — слайдер в меню, по умолч. 100). Кнопка **✓**
  в шапке завершает раунд досрочно и уводит к итогам/комментированию; **↻** — начать заново.
- Слово **появляется по центру без падения** (метод **Spritz**): центральная литера
  (ORP — точка оптимального распознавания) подсвечена акцентом и закреплена ровно по
  центру playfield (грид `1fr auto 1fr` + риски-крест), кегль подбирается под длину —
  глаз не двигается между словами. Карточка ждёт нажатия, промахнуться нельзя.
- Управление: BAD `←`/`A`/`Space`, GOOD `→`/`D`/`Enter` (вкл. numpad), SKIP `↑`/`W`.
  WASD/Space — по `e.code`, Enter/стрелки — по `e.key` (любая раскладка).
- **Свайп карточки** (тач + мышь, `enableDrag` на pointer-событиях): ← BAD, → GOOD,
  ↑ SKIP; ниже порога — возврат в центр. `touch-action:none` гасит скролл. Выход через
  инлайн-флинг (resolve(action, fling)). Мобильная вёрстка: тонкие корзины-счётчики,
  компактная шапка (`@media ≤560px`), кегль слова с `vw`-кэпом, ширина карточки от поля.
  На старт-экране **Enter/Space запускают раунд**. Авто-повтор зажатой клавиши (`e.repeat`)
  игнорируется — одно нажатие = одно действие.
- **Skip** не считается потраченным словом и **не** пишется в сыгранные — пропущенное
  может снова выпасть в будущем раунде.
- Каждое good/bad сразу пишется в `localStorage` (повторов в будущем не будет).
- Боковые поля = **живые счётчики** улетевших слов (good справа, bad слева), а не подписи.
- **Серии (streak):** цепочка ≥3 подряд в одну сторону всплывает баннером
  «GOOD/BAD STREAK ×N» у нужного края; смена стороны сбрасывает счётчик, skip нейтрален.

### Адаптивный подбор (рычаг 1)
Вместо равномерного рандома выпадающие слова смещаются к выученному вкусу:
- **Признаки слова** (`featuresOf`): язык, часть речи, длина-бакет, слоги, класс
  начального звука (плос./фрик./лик./нос./глайд/гласн.), гласное/согласное окончание,
  дубль. Считаются по видимому токену (для grc/el/sa — транслиту).
- **Модель вкуса** — наивный байес: на good/bad копятся счётчики признаков, скор слова
  = Σ log((good+1)/(bad+1)). Хранится в `localStorage` (`sorter.taste.v1`); `skip` не учит.
- **Выборка** (`drawNext`) — Больцман по случайному окну (≤500): `exp(score/T)`, где `T` —
  «температура» от ползунка **разведка↔фокус** (1.25 → 0.20). До `WARMUP`=10 оценок и при
  выключенном тумблере — равномерно. Слова тянутся по одному вживую (модель учится между
  карточками), `round.remaining` шринкуется сплайсом.
- Меню: тумблер «учить мой вкус», ползунок, счётчик выученного, «Сбросить вкус».
- Проверено: модель «любит IT / не любит LA» при фокусе даёт ~98% IT (база ~13%); в
  разведке ~71% при 6 языках в выдаче; LA → 0% в обоих.

### Режим ковки (рычаг 2)
Генеративный слой: коины из твоих **good-слов** (корпус `sorter.goodcorpus.v1` — туда
падают одобренные словарные слова в «Поиске»; коины обратно в корпус не идут).
- **Ингредиенты** (`buildIngredients`): корпус, латинизированный (`latinize` кириллицы +
  NFD-снятие диакритики). Своих < 24 — добор топ-словарными **по вкусу** (`tasteScore`).
- **Генераторы** (`gen`, 5): бленд (head+tail с оверлапом), аффикс (-o/-ia/-ex/-ova…),
  усечение, компаунд, мутация (c→k, ph→f, сдвиг гласной, дубль). Фильтр `sayable`: 3–11
  букв, есть гласная, нет 4+ согласных подряд и тройных букв; дедуп против сыгранных.
- Коин = `{w, g:провенанс, lang:"coined", forged:true}`. Карточка: бейдж ✦, метка «коин»,
  вместо глосса — происхождение («бленд · A + B»). Адаптив ранжирует коины тем же
  экстрактором (судит по звуку → рычаги 1 и 2 складываются).
- **Включение:** тумблер **«Поиск / Ковка»** на старте + кнопка **«Ковка ✦»** на итогах
  (`round.forge`). Экспорт коинов — с `lang=coined` и провенансом.

### Экран итогов
Две колонки GOOD / BAD. Поле комментария — **только у GOOD**; плохие слова не
комментируются. Кнопки «Экспорт .txt» и «Новый раунд».

### Экспорт `.txt`
Имя файла `round_<NN>_<YYYY-MM-DD>.txt`, tab-separated. **В файл идут только GOOD-слова**
(с комментариями, где есть); плохие в экспорт не попадают, в шапке остаётся лишь счётчик
`bad` как статистика. Пустой комментарий → `—`.

```
# раунд 7 · 2026-06-04 · сыграно 100 · good 18 · bad 82
# колонки: слово \t язык \t глосс \t комментарий
## GOOD
такелаж	ru	оснастка судна; снасти	морская семья
νίκη (níkē)	grc	victory, success	—
```
Для grc/el/sa в колонке «слово» — `оригинал (транслит)`.

### Ключи localStorage
`sorter.played.v1` (сыгранные), `sorter.settings.v1` (языки, длина, слов в раунде, адаптив),
`sorter.roundno.v1` (счётчик раундов), `sorter.lastround.v1` (бэкап последнего раунда),
`sorter.taste.v1` (модель вкуса), `sorter.goodcorpus.v1` (good-слова — ингредиенты ковки).
«Сбросить историю» очищает `played`; «Сбросить вкус» — `taste`.

## Данные: как собрать пулы (одноразово, оффлайн)

Рантайм в сеть не ходит — пулы готовятся заранее.

```
bash scripts/fetch_all.sh         # качает kaikki + частоты, стримит в build_pools.py
```

Что делает оркестратор:
1. **Источник** — [kaikki.org](https://kaikki.org) (Wiktextract), машиночитаемый
   Викисловарь, JSON Lines, лицензия CC-BY-SA. Per-language дампы (English ~3 ГБ,
   Latin ~1.2 ГБ и т.д.) **стримятся** через `curl | python3` — на диск гигабайты
   не падают.
2. **Частоты** (опц., для ru/en/fr/it/el) —
   [hermitdave/FrequencyWords](https://github.com/hermitdave/FrequencyWords)
   (OpenSubtitles). Берётся средне-частотная полоса: отсекаются и бытовой верх, и
   сверхредкий хвост.
3. `build_pools.py` фильтрует и нормализует (см. ниже), пишет `data/pool_<lang>.jsonl`.

`fetch_all.sh` пропускает уже собранные пулы (по наличию непустого файла) — повторный
запуск дособирает только недостающие языки. Лог — `logs/build.log`.

### Что делает build_pools.py
Читает JSONL из **stdin**, пишет пул. Фильтры:
- части речи: только `noun / adj / verb` (частицы, союзы, предлоги, местоимения,
  артикли, междометия, аббревиатуры — вон);
- длина `w`: 2–18 символов для однословных; словосочетания — не длиннее 3 слов;
- выкидываются значения с тегами `vulgar / offensive / derogatory` и глоссы-«не-слова»
  (формы, отсылки, имена собственные);
- дедуп внутри языка;
- `tr` для grc/el/sa — из `forms[*]` (tag `romanization`), для греческого есть
  запасная детерминированная латинизация; без `tr` запись отбрасывается.

Два режима выборки:
- **freq** (ru/en/fr/it/el): берём слова из частотной полосы `[--freq-lo, --freq-hi)`.
- **reservoir** (la/grc/sa): равномерная выборка по всему файлу (иначе был бы
  алфавитный перекос к началу дампа). Cap по умолчанию 40 000 на язык.

Запуск вручную для одного языка:
```
curl -sL "<kaikki-url>" | python3 scripts/build_pools.py --lang ru --freq data/freq_ru.txt
curl -sL "<kaikki-url>" | python3 scripts/build_pools.py --lang la            # reservoir
```

> ⚠️ Системный bash на macOS — 3.2: в `fetch_all.sh` не используем `set -u`
> (падает на пустых массивах). Если меняешь скрипт — помни про это.

### Добавить/обновить язык
Добавь строку `build <code> "<kaikki-url>" [freq-код]` в `fetch_all.sh`, заведи код в
`LANGS` (game.js) с бейджем, при необходимости — в `TR_LANGS`. Перезапусти `fetch_all.sh`.

## Шрифты

Самохостятся (`scripts/fetch_fonts.py` → `assets/fonts/`): **Inter** (дисплейный,
крупные токены; есть кириллица/латиница/греческий) + **Spline Sans Mono** (ярлыки,
счётчики). Оригинальное письмо (деванагари/греческий мелким) — системные шрифты macOS
(`--script` в CSS). В сеть рантайм не ходит.

## Эстетика

Тёмная тема, чёрный фон, акцент `#71FCE9` (как в прошлых артефактах проекта), сетка и
свечение в духе пэда «Tune Sound». Микроанимация ухода карточки в корзину, лёгкий ритм.
Один экран игры, один экран итогов, маленькое меню (языки, длина слова, слов в раунде, сброс).

## Деплой

Как и матричный движок — в репозиторий **`barinboim/brnbm`**, отдельной папкой
(напр. `namer/sorter/`). Пулы `data/pool_*.jsonl` залить вместе с кодом (это и есть

(нужны только для пересборки). Пример — см. CLAUDE.md в корне репо.
